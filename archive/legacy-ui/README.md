# Retired LifeOS demonstration UI

These components were removed from the production `src` tree on 2026-07-20.
They were not imported by the active LifeOS application and contained fabricated
enterprise telemetry, localStorage demo state, placeholder integrations, or
prototype-only workflows.

They remain here for design reference and Git history. This directory is not
compiled, bundled, tested, or served. A component must not be restored to
production until its data sources, persistence, authorization, and tests are real.

The supported personal product surface is Dashboard, Plan, Daily, Finance, Work,
Assistant, Memory, Connections, and Preferences.
